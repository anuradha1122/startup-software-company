# IT Hub — Project Overview

## Stack

- Laravel 13
- PHP 8.4+
- React 19
- TypeScript
- Inertia 3
- Tailwind CSS
- MySQL
- Pest

## Purpose

Internal software-company ERP / PSA system managing:

Lead → Client → Requirement → Estimate → Proposal →
Quotation → Contract → Project → Work → Cost →
Invoice → Payment → Profitability → Support.

## Development Rule

Each module must be completed with its applicable:

- Backend
- React UI
- permissions
- validation
- database
- PDF
- Excel
- notifications
- emails
- tests
- documentation

before moving to the next module.

## M05

M05 establishes the transition from signed commercial agreement to
governed software project.

A project inherits its commercial and scope baseline from the signed
contract and cannot redefine that baseline.

## M06

M06 adds project execution workflow.

Work originates inside an active M05 project and is organized through
tasks, workflow statuses, dependencies, work submissions and formal
review.

## M07

M07 formalizes operational people, skills and project staffing.

Users become eligible M06 task assignees only while they hold an
active assignment on the relevant project.

HR employment administration remains outside this module and is
reserved for M15.

## M08

M08 records actual project work time and converts approved hours into
private internal project cost.

Time entries reference M06 tasks and M07 project assignments.

Internal cost information is never client-facing.
