# Roles & Permissions

- Admin

- Finance

## M00 Permissions

- users.view
- users.create
- users.update
- users.delete
- users.export
- roles.manage
- company-settings.view
- company-settings.update
- audit.view
- audit.export

Director and Admin receive every M00 permission.

Permissions are assigned to roles rather than directly to users.
